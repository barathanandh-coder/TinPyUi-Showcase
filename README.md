# TinPyUI Showcase

> Pure TinPyUI framework showcase. Built entirely with `.tin` syntax.

## Links

- **npm:** https://www.npmjs.com/package/tinpyui
- **GitHub:** https://github.com/barathanandh-coder/tinui

## Quick Start

```bash
npm install -g tinpyui
tinpyui init my-app
cd my-app
tinpyui compile src/index.tin
tinpyui serve
```

## File Structure

```
tinpyui-showcase/
├── src/
│   └── index.tin          # ← EDIT THIS FILE ONLY
├── public/                # ← AUTO-GENERATED by tinpyui compile
│   ├── index.html
│   ├── wasm_exec.js
│   ├── tinui_engine.wasm
│   └── app.ir.json
├── app.py
└── tinpyui.config.json
```

> **Do NOT edit files in `public/`.** They are auto-generated by the compiler.

## Components Used

All components are **built-in TinPyUI components** — no custom components needed:

- `AnimatedBackground` — Dynamic background
- `Navbar` — Top navigation
- `NavLink` — Navigation links
- `Section` — Content sections
- `Row` — Horizontal layout
- `Column` — Vertical layout
- `Grid` — CSS grid layout
- `Text` — Typography (with styling props)
- `Input` — Form input with data binding
- `Spacer` — Empty space
- `Footer` — Page footer
